About This System

This platform represents an advanced AI-based Chronic Kidney Disease (CKD) prediction engine. It leverages state-of-the-art gradient boosting algorithms—LightGBM and CatBoost—to analyze complex clinical biomarkers effectively and generate highly accurate diagnostics.

🔬 Feature Engineering Methods

Method Category Analytical Role
Mutual Information Filter Identifies complex non-linear interdependencies between biomarkers and the diagnosis curve.
Chi-Squared (χ²) Filter Statistical validation measuring independence strength to rank the relative value of features.
ANOVA F-test Filter Variance analysis testing linear independence between categorical and numerical vectors.
Recursive Selection (RFE) Wrapper Model-driven elimination using LightGBM feature importance matrices iteratively.
